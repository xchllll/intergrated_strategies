## 5. 解释

- 新 RL 的高频衰减是输入网络的一部分，H 平面表通过该行的实测 `H` 学习了这部分网络响应，因此不需要把它当“坏数据”剔除；
- 新 RLC 在低频呈现高电容相位，在 1.6 kHz 附近过谐振，补足了旧表在谐振区的相位样本；
- 新表仍使用当前 persistent session 的 5 轮短接表，避免短接表切换引入的整段相位偏移。

## 6. 限制

1. 这是 in-sample 校验，不是独立测试；新标准件误差接近 0 不代表对未知 DUT 的泛化误差。
2. 12 组旧标准件来自旧 session，而新表短接表是当前 session；旧行的残差主要来自这个 session 差异和 50 Hz 干扰。
3. 新 RL 的 `R=3.87 kΩ` 是总串联电阻假设；如果实际电阻还包含未计入的 DCR，建议用实测总电阻重新建表。
4. 新 RLC 使用标称 `1.98 kΩ + 98.7 mH + 98.11 nF`；如果实际元件值有明显偏差，应替换参数后重建。
