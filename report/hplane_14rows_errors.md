## 复核方法

```bash
python check_hplane.py        # 用当前 calibration_table.json 与 14 行表重算
python plot_hplane_errors.py  # 输出误差曲线 PNG
```

`check_hplane.py` 需要 14 组标准件的原始扫频历史（仓库 `data/history.csv` + 对应的历史快照），以及当前短接表 `data/calibration_table.json`。
