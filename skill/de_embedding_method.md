# 去嵌入校准方法（De-embedding Calibration）

> 适用对象：PYNQ-Z2 + ADAU1761 + 自研 PL 正交解调链路，DUT 串接在 HP 输出与 line-in 节点之间。
> 目标：只用“短接”和“已知标准件”两组测量，把 DUT 的真实阻抗/传递函数从测量环路中分离出来，并校正高频段（>2 kΩ 负载）的幅相塌陷。

## 1. 测量拓扑与原始方程

```
HP out ──► R_dut (DUT) ──► line-in 节点 ──► ADC
                                │
                              Zin(f)（输入网络，对地）
```

- `Zin(f)`：输入网络阻抗，低频约 **10.986 kΩ**，高频因并联电容/串联电感而下降并相移。
- 测量量是分压比：

```
H_true(f) = V_line / V_src = Zin / (R_dut + Zin)
```

- 反解 DUT：

```
Z_dut(f) = Zin(f) · (1 - H_true) / H_true
```

- 但实际读到的是 `raw`，它包含 DDS、I2S、codec DAC/ADC、PL 解调、积分窗等一整套环路响应 `S(f)`：

```
raw(f) = S(f) · H_true(f)
```

去嵌入就是先消掉 `S`，再消掉 `Zin`，最后换回“以 R_ref 为参考”的显示量。

## 2. 三层校准

### 2.1 第一层：短接（消环路）

短接时 `R_dut = 0`，理论上 `H_true = 1`，所以短接测量 `S(f)` 就是环路本身。校准系数取倒数：

```
H_cal(f) = raw(f) · (1/S(f))      # 复数：gain·e^{jφ}
```

工程上存成 `mag_gain = 1/|S|`、`phase_offset_deg = -arg(S)`，或者等价的 `h_re/h_im` 复数系数。之后任意 DUT：

```
H_cal = raw · mag_gain · e^{j·phase_offset}
```

短接的 H 被强制为 1，环路整体（含 ±180° 回绕、群延迟、滤波器）一次性消掉。

### 2.2 第二层：输入网络（消 Zin）

`Zin(f)` 不是常数：低频 10.986 kΩ，高频因 10 nF 级并联电容和 ~9.8 mH 级串联电感而下降。用一张 **H 平面表**描述它：

- 每条标准件曲线存 `(f, H_row(f), Zin_row(f))`；
- 测到 DUT 的 `H_cal` 后，在 **复平面 H** 上做反距离加权，取最近的若干条标准行，插值出 `Zin(f)`；
- 再反解：

```
A   = H_cal                       # 直连路径；buffer 路径 A = H_cal·(1+L) - L
Z_dut = Zin(f) · (1 - A) / A
```

用复平面而不是只看 `|H|`，是因为同一电平下纯电阻和容性 RC 的相位不同，只按幅度插值会在 6.6–6.9 kHz 附近插出假陷波。

### 2.3 第三层：显示参考（R_ref）

最终网页显示的是“以 `R_ref` 为参考”的分压：

```
H_disp(f) = R_ref / (Z_dut(f) + R_ref)
```

`R_ref` 由 97.2 kΩ 标准件的低频 `Z` 取中位数得到，约 **10.98 kΩ**，代表“如果 DUT 是理想电阻，分压比应该是多少”。这样纯电阻 DUT 显示为 0 dB/0°，RC/RL 显示为它们相对 `R_ref` 的真实衰减与相移。

## 3. 算法总流程

```
raw(f)
  │  ① 短接表：H_cal = raw · gain · e^{jφ}
  ▼
H_cal(f)
  │  ② H 平面表：zin_at(f, H_cal) → Zin(f)
  ▼
Z_dut(f) = Zin · (1 - H_cal) / H_cal
  │  ③ 显示参考：H_disp = R_ref / (Z_dut + R_ref)
  ▼
H_disp(f)（网页/历史里的 mag_db_cal、phase_deg_cal）
```

对应代码：

| 步骤 | 文件 | 函数 |
| :--- | :--- | :--- |
| ① 短接去嵌入 | `python_model/calibration.py` | `apply_calibration()` / `deembed_complex()` |
| ② 输入网络插值 | `python_model/input_network.py` | `zin_at()` / `deembed_complex()` |
| ③ 显示参考 | `python_model/input_network.py` | `H_disp = R_ref/(Z+R_ref)` |

## 4. H 平面表的结构

`data/input_network.json`（format 3）：

```json
{
  "format": 3,
  "freqs": [20.0, ...],                // 240 点
  "levels": [0.0997, ...],             // 每行 |H| 的中位数，用于排序/查找
  "level_f": [[...], ...],             // 每行逐点 |H|
  "h_re":   [[...], ...],              // 每行逐点 Re(H)
  "h_im":   [[...], ...],              // 每行逐点 Im(H)
  "zin_re": [[...], ...],              // 每行逐点 Re(Zin)
  "zin_im": [[...], ...],              // 每行逐点 Im(Zin)
  "R_ref": 10982.5,                    // 显示参考
  "short_ref": {"mag_gain": [...], "phase_offset_deg": [...]},  // 建表短接（可无）
  "rlc": {...}                         // 等效 RLC 参数（可选）
}
```

13 条标准行（按 `levels` 升序）：

| # | 行名 | 类型 | 参数 |
| :--- | :--- | :--- | :--- |
| 1 | `97k2` | 纯电阻 | 97.2 kΩ |
| 2 | `51k4` | 纯电阻 | 51.4 kΩ |
| 3 | `rc11k6` | RC 串联 | 11.6 kΩ + 10 nF |
| 4 | `rc1k98` | RC 串联 | 1.98 kΩ + 10 nF |
| 5 | `rc1k473` | RC 串联 | 1.473 kΩ + 10 nF |
| 6 | `rl9m8_11k6` | RL 串联 | 11.6 kΩ + 9.8 mH |
| 7 | `9k2` | 纯电阻 | 9.2 kΩ |
| 8 | `rl101m7_2k03` | RL 串联 | 2.03 kΩ + 101.7 mH |
| 9 | `rl9m8_2k03` | RL 串联 | 2.03 kΩ + 9.8 mH |
| 10 | `2k04` | 纯电阻 | 2.04 kΩ |
| 11 | `1k473` | 纯电阻 | 1.473 kΩ |
| 12 | `rl9m8_1k032` | RL 串联 | 1.032 kΩ + 9.8 mH |
| 13 | `1k02` | 纯电阻 | 1.02 kΩ |

插值方式：

1. 对每条标准行，在 `log f` 上线性插值出该频率的 `H_row`、`Zin_row`；
2. 在复平面上算距离 `d = |H_cal - H_row|`；
3. 反距离权重 `w = 1/(d² + 1e-6)`，归一化后加权平均得到 `Zin(f)`；
4. 只对 `|H_cal| < 0.999` 的点做去嵌入，接近 1（接近短路）时直接返回原 `H`，避免除零放大。

## 5. 直连校准表的结构

`data/calibration_table.json`（format 2）：

```json
{
  "format": 2,
  "meta": {"created": "...", "ref_amp": 1.0, "dac_volume": 16,
           "source": "dashboard startup reference (short)", "freq_points": 240},
  "rows": [
    {"freq": 20.0,
     "direct": {"mag_gain": 4.27e-5, "phase_offset_deg": 86.0,
                "h_re": ..., "h_im": ...},
     "buffer": null}
  ]
}
```

- `direct`：直连路径（本项目使用）；
- `buffer`：带缓冲/衰减的路径（预留）；
- 幅值按**对数**插值、相位按**增量**（`wrap(p1-p0)`）插值，跨 ±180° 不错位；
- 原子写：先写 `.tmp`、`fsync`，再 `os.replace`；失败时旧表不变；
- 元数据记录 `dac_volume`，驱动电平变化时能告警。

## 6. 启动参考（短接自动重测）

H 平面表的每行 H 都是 `raw × 短接表`，短接响应在表里会**抵消**：

```
raw = S · H_true
短接表 = 1/S
H_row = raw · 短接表 = H_true_row
```

所以表本身与“建表用哪张短接表”无关，但**测量时必须用当前进程的短接**。启动参考就是为此存在：

1. `run_dashboard.py` 默认 `START_WITH_REFERENCE=1`，主线程先 `_ensure_rtl_design()`（pynq 需要主线程 asyncio loop）；
2. 后台线程跑一轮 240 点短接扫频（`n_target=1000`，周期 10–410，约 20 s）；
3. 网页立即可用，但“开始扫频测量”按钮禁用并提示“正在进行相位对齐”；`/api/start_sweep` 返回 409；
4. 240 点全部结束后才 `cal.CAL_TABLE = rows` + 原子写盘；中途失败则旧表不变、按钮恢复；
5. 参考只用前 5 个频点做“是否短接”的绝对幅度判据（0.98–1.02，按 DAC 音量归一化），不通过立即停止。

## 7. 采样平移与相位

链路是 100 MHz / 2048 = **48828.125 Hz** 采样，一个采样 **20.48 µs**。重启进程时，I2S 帧起点相对采样计数器的相位可能差一个采样（实测约 **24 µs**），在 20 kHz 就是 **100°~147°** 的相位偏差。RTL 用 `start_pending` + `rx_data_valid` 把启动对齐到帧边界，解决了**进程内**的漂移；**跨进程**仍会差一个采样，所以需要启动参考把当前短接重新测出来。短接表与 H 平面表必须来自**同一进程**，否则 20 kHz 会崩（曾出现 −2.50 dB/−79°、−2.70 dB/−116°）。

## 8. 验证

- 9.8 mH + 11.6 kΩ：20 Hz −6.27/−0.18°、1 kHz −6.26/−2.46°、10 kHz −6.79/−19.35°、20 kHz **−6.28/−3.14°**；模型 −6.26/−6.26/−6.27/−6.28，20 kHz 相位 −3.12°。
- 短接扫频：20 kHz 0.00 dB/0.00°，全频段 ±0.07°。
- 纯电阻：1.02 k/1.473 k/2.04 k/9.2 k/51.4 k/97.2 k 均回到 0 dB/0° 附近。

## 9. 局限

1. H 平面表只覆盖已测过的标准件；落在行间、且相位差异大的 DUT（如任意大电感）靠 IDW 近似，误差会变大。
2. `|H|` 接近 1（近短路）时去嵌入的病态问题无法根除；需要绝对幅度判据和标准件覆盖。
3. 标准件本身的容差（±1%）会直接进入表；本项目用万用表阻值而非标称值建表。
4. 每次新进程都必须重测短接（启动参考）；若不想依赖短接，需要从 RTL 上彻底消除跨进程帧相位差，或改用固定物理模型。
